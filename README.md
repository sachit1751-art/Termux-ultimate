# 🚀 Termux Ultimate

> Transform Termux into a modern AI-powered development environment with a single command.

## Features

- 🐚 Oh My Zsh
- ⚡ Powerlevel10k
- 🎨 Catppuccin & Tokyo Night themes
- 🤖 Ollama
- 🧠 Gemini CLI
- 🐍 Python Development
- 🟢 Node.js Development
- 📦 pnpm & Yarn
- 🎥 yt-dlp + FFmpeg
- 🔍 eza, bat, fd, ripgrep
- 📊 Fastfetch
- 📈 btop / htop
- 🖥️ tmux
- 🔄 Self Update
- 🛠 Self Repair
- 📜 Installation Logs

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/sachit1751-art/Termux-ultimate/main/install.sh | bash
```

> Installation command will work after the first stable release.
